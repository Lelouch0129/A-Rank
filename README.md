# A-Rank
AI-powered valuation and scoring application built with Python and Streamlit

# A-Rank

**An AI-assisted valuation application that turns real-world objects and subjective experiences into explainable estimates and A-Scores.**

A-Rank is a Python/Streamlit application that accepts text or image input, identifies one or more items to evaluate, gathers relevant context, and produces valuations with supporting explanations.

Its core design separates **LLM-driven interpretation and evidence collection** from **deterministic Python calculations**.

## Highlights

- **Multi-item analysis:** Detect and evaluate multiple objects in a single request while keeping each item's context and results separate.
- **Adaptive clarification:** Generate up to three targeted follow-up questions when important valuation details are missing.
- **Three valuation modes:** Route items to market-based, model/proxy-based, or entertainment-oriented evaluation depending on the nature of the item.
- **Market evidence processing:** Retrieve comparable-price candidates with OpenAI's web search tool, filter low-relevance entries, and remove statistical outliers using median absolute deviation (MAD).
- **Context-aware experience valuation:** Account for subjective or situational value associated with a physical item without conflating it with its market price.
- **Structured model outputs:** Validate model responses with JSON schemas and Pydantic models before using them in downstream calculations.
- **Explainable results:** Present estimated value ranges, confidence indicators where applicable, A-Scores, and AI-generated commentary.

## Architecture

```text
Text / Image Input
        |
        v
Input Analysis & Routing (LLM)
  - Identify individual items
  - Select valuation mode
  - Determine whether clarification is needed
        |
        v
Optional Clarification (up to 3 questions total)
        |
        v
+------------------------+----------------------------+
| Real-asset modes       | Entertainment mode         |
| (market / model)       | (subjective valuation)     |
|                        |                            |
| Web-search comparables | LLM-generated subjective   |
| -> relevance filtering | valuation and explanation  |
| -> MAD outlier removal |                            |
| -> median-based value  |                            |
| -> optional experience |                            |
|    overlay             |                            |
+------------------------+----------------------------+
        |
        v
A-Score & Results Presentation (Streamlit)
```

The LLM handles item identification, interpretation, evidence gathering, and narrative generation.

Python handles comparable-price filtering, aggregate valuation, confidence calculations, and score computation for real assets.

**Entertainment valuations are intentionally subjective and generated by the model**, rather than being presented as independently verified market values.

## Valuation Logic

### 1. Market-Based Estimates

For real assets, A-Rank collects comparable-price candidates and uses the following pipeline:

1. Keep candidates with positive CNY prices and a relevance score of at least 0.5.
2. Remove anomalous prices using **median absolute deviation (MAD)** and a robust Z-score threshold. A fallback handles the zero-MAD case.
3. Use the **median** of the remaining prices as the best estimate; the minimum and maximum form an indicative range.
4. Compute a heuristic confidence score using comparable count, price consistency, and average relevance, with additional caps for limited evidence or model/proxy mode.

This is a heuristic estimation pipeline, not a guarantee that external prices are accurate or current.

### 2. Experience Overlay

For certain physical items, the application combines an estimated market anchor with a subjective, context-specific premium:

```text
Material Value     = Anchor Price x Material Fraction
Experience Premium = Anchor Price x Experience Share x Context Intensity
Final Value        = Material Value + Experience Premium
```

The LLM supplies dimensionless context parameters; **Python computes the monetary amounts**.

These premiums represent an experimental subjective model and should not be interpreted as fair-market value.

### 3. A-Score

A-Rank compresses a CNY-denominated valuation into a logarithmic score:

```text
A-Score = 1 + log10(Value in CNY)
```

For positive values:

| Valuation (CNY) | A-Score |
|-----------------|---------|
| ¥1              | A1.00   |
| ¥10             | A2.00   |
| ¥100            | A3.00   |
| ¥1,000          | A4.00   |
| ¥10,000         | A5.00   |
| ¥100,000        | A6.00   |

The implementation returns `0.0` for nonpositive input values.

## Getting Started

### Prerequisites

- Python 3.10 or newer
- An OpenAI API key with access to the configured models and required API capabilities

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/A-Rank.git
cd A-Rank
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the environment:

**macOS / Linux:**

```bash
source .venv/bin/activate
```

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

### Environment Configuration

Create a local `.env` file in the project root:

```dotenv
OPENAI_API_KEY=your_api_key_here
OPENAI_MODEL=your_supported_model
OPENAI_ENTERTAINMENT_MODEL=your_supported_model
# Optional: OPENAI_EXPERIENCE_MODEL=your_supported_model
```

Set the model names to models available in your OpenAI account.

The source code contains default model names; override them if those model identifiers are not available in your environment.

Market comparison requests use the OpenAI `web_search` tool and require compatible API access.

**Security:** Never commit `.env`, API keys, or other credentials to the repository.

### Running the Application

Start the Streamlit server:

```bash
streamlit run app.py
```

Open the local URL displayed in the terminal.

## Engineering Design Decisions

### Separation of AI and Deterministic Logic

Instead of allowing an LLM to directly determine all numerical results, A-Rank assigns different responsibilities to different components.

**LLM responsibilities:**
- Interpret user input
- Extract item information
- Generate clarification questions
- Gather market evidence
- Produce structured contextual analysis
- Generate natural-language commentary

**Python responsibilities:**
- Validate and filter price candidates
- Remove statistical outliers
- Aggregate market estimates
- Calculate confidence scores
- Apply experience-valuation formulas
- Compute final A-Scores

This architecture makes the numerical valuation process more transparent and easier to inspect.

### Schema-Driven Data Validation

The application uses Pydantic models and JSON schemas to define data contracts between AI components.

Structured responses are parsed and validated before being passed to downstream calculation modules.

Additional application-level validation handles cases such as invalid item references, duplicate clarification IDs, and excess clarification questions.

### Robust Statistical Filtering

Market comparable prices are processed using relevance thresholds and median absolute deviation.

Compared with using the arithmetic mean directly, median-based aggregation is less sensitive to extreme price observations.

## Limitations

- External price data may be incomplete, outdated, or inaccurate.
- Confidence scores are heuristic indicators, not statistically calibrated probabilities.
- Entertainment and experience-based valuations are subjective.
- Application execution requires a valid OpenAI API key and compatible model access.
- The system has not been independently benchmarked for latency, accuracy, or scalability.
